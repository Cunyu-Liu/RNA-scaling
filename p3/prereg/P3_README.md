## 2. 两臂的关键科学合同

### P3.1：饱和稳健

- 已有 s17 不重复训练；只补 300M/650M 的 s29/s43，终点均为 2.0B valid nt、同 RNA-Sc 配方。
- 主终点固定为 100M→650M 同训练种子配对斜率，100M 锚为 0.3263/0.3365/0.3553，既有 0.0293 仅为单种子档结果。
- 报告三种子均值±样本 SD（ddof=1）和 n=3 配对 Student-t 95% CI；**CI 上界严格 <ε=0.03 才写“饱和稳健”**。点估计 <ε 但 CI 跨 ε 时，降级为“单种子档观察到，三种子档支持趋势”。
- 300M→650M 是辅助上段斜率，不得事后替换主终点；序列 bootstrap 不替代训练种子 CI。

### P3.2：曝光归因

- 必须有 A=既有 R22/2B、B=新 RiNALMo 语料/2B、C=新同语料/六簇 epoch 三格。只训 C 无法分离语料与曝光；用旧 30M/100M/300M 复刻臂替代 B 也不能回答 650M 差距。
- RiNALMo 制度是约 36M 序列、17M 簇、每簇每 epoch 抽一条、共 6 epochs，长序列每 epoch 随机 crop；不是将现有 14M parquet 普通循环六次。
- 主对比为 `corpus=B−A`、`exposure=C−B`，外部 `R−C` 始终是联合残差。按序列 bootstrap 只量化评估样本不确定性，不冒充训练种子重复。
- 现有 v1 仅 14,026,879 条且备份 parquet 页脚不可读，v2 也只有 18,510,642 条；二者都不是本协议语料。若一月期限不允许完成六 epoch，本臂不触发，不能静默缩短。
