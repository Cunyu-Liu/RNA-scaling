## ① 六档 family F1 与 100M→650M 斜率

**证据：** `B/eval_evidence_logs/eval/probe_results.jsonl`（3,430 条 JSONL 记录）。

**独立口径：**

1. 只取 `run == RNA-Sc-{scale}_{seed}`，排除 `_ck...`、`_b59`、randinit、mommatch 和其他干预臂。
2. 只取 `split == family_validation->family_test`、`n_train == 20000`、`n_eval == 4000`。
3. 每个 run 先取最大 `ckpt_nt` 的终检点，再按 `f1_macro` 选最佳层。此顺序避免把同一 run 的早期检点混入。
4. 1M/10M/30M/100M 对 s17/s29/s43 取算术均值；300M/650M 只取 s17。
5. 斜率直接使用未舍入的 100M 三种子均值计算，不以四位小数展示值替代中间量。
