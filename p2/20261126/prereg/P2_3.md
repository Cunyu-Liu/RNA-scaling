## 1. 保住的主张与边界

在相同 bpRNA 前向干预下测外部 MLM 的 COV−CTRL，并与各自 randinit 对照，互证“结构知识可存在于前向读出而不必然转化为线性探针能力”的跨模型适用范围。本任务只补 COV；线性读出墙引用既有同任务探针表，不重新训练外部探针。

外部模型语料、架构和训练量不受控，禁止把模型间差值归因于某一语料或参数定律。RNA-FM 缺权重不得阻塞其他模型。

## 3. 冻结 COV−CTRL 协议

权威可执行来源是 `$B/code_git/run_cov300.py`；原 `/tmp/covariation_test.py` 未在 `code_git` 留存，不能作为唯一复现依赖。执行时把 `run_cov300.py` 的完整定义迁入 P2 新脚本并冻结哈希，旧 300M 数值作 sanity anchor。

1. 数据：`bpRNA_parsed.parquet`，全部 `split=test` 共 1,305 条；`random.Random(17)` 抽 100 条，ACGU 清洗、T→U、最长 256nt，长度<20 跳过前向但保留抽样/RNG 顺序。
2. 条件只生成一次并落盘：有效 pair 转 0-based，RNG 打乱后每序列最多 20 对；i 的三种非原碱基突变；unpaired k 必须距 i、j 均>5nt。保存 sequence ID、i/j/k、原碱基、mutations，所有模型共用。
3. mask j，读 j 的原始和突变后互补碱基概率；对 k 重复同样操作。`COV=mean[p_mut(COMP[m])−p_orig(COMP[m])]`，`CTRL` 同理；**COV−CTRL=全 mutation pooled mean(COV)−pooled mean(CTRL)**。同时保存 old_drop 作诊断，不作 headline。
4. 参考旧证据：100 条样本通常产生 cov_n=ctrl_n=4,920；实际以冻结条件 manifest 为准。所有模型必须共享完全相同的有效 condition 数和序列/pair ID，数量不同即停止跨模型比较。
5. eval、no_grad、BF16 autocast，初始 condition batch=16。不同模型仅改变 tokenizer/special-token offset 和 MLM adapter，核苷酸干预及读出碱基不变。
6. 每个模型报告 COV、CTRL、COV−CTRL、randinit COV−CTRL、trained−randinit；不设置“必须为正/必须超过自训模型”的结果门槛。

## 4. 种子

bpRNA 样本/pair/CTRL=17；randinit=17。COV 无探针头；不做训练种子或序列 bootstrap 冒充。可选序列 bootstrap 仅作敏感性，seed17 并明确其含义。

## 6. 失败降级

- 缺 RNA-FM：主表保留空缺失状态，跨模型结论限 RiNALMo+NB；不得从既有 family 探针反推 COV。
- tokenizer/MLM 头无法验证：该模型 `FAILED_ADAPTER`，不输出伪 COV；若全部外部模型失败，Q5 跨模型主张继续限定自训家族。
- OOM：batch 16→8→4→1，条件集不变；batch=1 仍 OOM 或 CUDA 不可用则停止该模型，禁止 CPU 静默降级。
- randinit 未完成时 trained 值只能标“缺自身零基线”，不能用于“全部来自预训练”的强表述。

## 7. 资源估算

micro/NB 每进程约 4–7GB，mega/giga 约 5–9GB；100 条、约 13k 个干预前向（batch16）每模型约 10–30 min，randinit 相同。四个训练+四个 randinit 串行约 1.5–4h；RNA-FM 若补入另加约 20–60 min。时间为 5090 估算，实际由 smoke 后更新日志，不改变终点。
