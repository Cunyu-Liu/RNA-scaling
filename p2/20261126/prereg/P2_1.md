## 3. 冻结协议

权威脚本：`$B/code_git/rna_sc/probe_structure.py`，权重加载：`$B/code_git/rna_sc/probe.py::load_encoder`。

- 数据：`bpRNA_parsed.parquet`；`split=train`（TR0）训练、`split=test`（TS0）评估。
- 用 `random.Random(17)` 先抽 8,000 条 train，再由同一 RNG 抽 1,500 条 test；序列清洗为 ACGU、T→U，截断 256 nt，少于 4 nt 跳过。
- 任务是逐位置 paired/unpaired 二分类；pair 坐标按原脚本 **1-based 转 0-based（i−1/j−1）**。使用逐 token 隐状态，不做序列 pooling；前向无 mask、eval、BF16 autocast。
- 全层扫描，L0–L11（30M）或 L0–L22（100M）。每层零初始化线性头，AdamW(lr=1e-3, weight_decay=0.01)，6 epochs，token batch=512；类权重 `[1, max(1,n_neg/n_pos)]`；头种子 **17+layer**。
- randinit 用 `torch.manual_seed(17)` 重建同架构编码器，训练探针协议不变。
- 执行版须给 `probe_structure.py` 增加显式 `--ckpt-nt` 并调用 `load_encoder(..., ckpt_nt=...)`；加载后断言 `ck["nt"]` 与请求值**完全相等**（原 loader 只选最近点，断言不可省略）。每行记录真实 `ckpt_nt`、checkpoint 文件名和 SHA256。不得靠“默认 latest”猜 1.8B，也不得用同名 run 覆盖两组账本。
- 每个单元在 TS0 上选最大 F1 的层；这是测试集选层的既有描述性协议，不包装成独立确认性泛化。

### 指标名纠偏（验收阻断项）

脚本注释声称 macro-F1，但 `macro_f1_binary()` 实际只返回 **paired 正类 F1**，旧账本字段为 `f1`；0.5924 也是这一口径。主复核指标因此命名为 `f1_paired_legacy`，同时保存 accuracy/precision/recall。执行版还须保存预测并补算真正的二分类 `f1_macro=(F1_unpaired+F1_paired)/2`，作为新增敏感性口径；没有同补丁 main-arm 重算前，不得用新 macro-F1 与旧 main 0.5890 混算。

## 7. 失败降级

- 缺权重/数据、CUDA 不可用、OOM 到最小安全批量仍失败：立即停止该单元并保存日志，禁止 CPU 静默降级。
- 若仅 1.9B 完成：只能补终预算点，旧值来源仍“未明”；若仅 100M 完成：通道特异性仍限单尺度并降 E1。
- 若旧曲线未复现：保留旧值为历史未固化记录，以新完整曲线另立口径并做显式差异裁决，不覆盖旧证据。
