# P2.6 预注册：RFamCap / RiNALMoCorpus / b59 新臂 de-rRNA 分层

- 状态：**已预注册，未执行**；主分析为纯 CPU 既有账本重聚合，无需 GPU。
- `$B` = 只读备份根；`$P` = 项目根 `补证_P2_20261125/`。

## 1. 保住的主张与边界

检验新臂 headline 是否由非 rRNA 类独立支撑：RFamCap 的语料效应、RiNALMoCorpus 复刻效应随尺度衰减、b59 预算效应的尺度依赖，以及 P2.5 重测的 650M>300M。若 rRNA 排除后方向消失/反转，相应“结构性结论”必须标未过，而非仍称语料/预算机制稳健。

本任务是固定探针预测的再聚合，不产生新训练种子，也不评估 random-split 记忆通道。`eval_matrix` random 行没有逐类 F1/预测，故 P2.7 不做伪 de-rRNA。

## 2. 协议与输入

函数口径来自 `$B/code_git/rna_sc/der_rna.py::macro_f1_excluding`；`der_rna_ext.py` 只提供外部模型先例，不是本新臂输入。

- 对每个层行读取 `per_class_f1`，剔除键名包含 `rRNA` 的类，其余非空类 F1 等权平均为 `f1_der`。沿用账本逐类四位小数，不把缺失类填 0；记录 all/der 类数及被排除类。
- 全层先重算，再按 `f1_der` 独立选 best layer；同时保存原 all-F1 best layer 的固定层 de-rRNA 值作选择敏感性。
- 主输入：`eval/probe_results.jsonl`（main、rfamcap、rinalmocorpus）和 `eval/probe_results_b59_family.jsonl`（b59）；P2.5 完成后再读其新 30 行。
- 选择官方 final：main/rfamcap/rinalmocorpus 用 `n_train>=4000` 且最大 `ckpt_nt` 的层行；b59 固定 `ckpt_nt=5800296014` 的原 20k/4k 行。重复行先去重并保留来源行号，不能当额外种子。
- RFamCap 终预算只用 **1,900,086,380nt**；历史 `ckpt_nt=200006790` 可列附录敏感性，但 +1.85pp 已撤回，不得复活。现存 1.800083135B 权重没有旧 family 层行时不得臆算 de-rRNA。

## 3. 对照表与科学终点

### RFamCap（s17 对 s17，终预算）

- 30M arm 0.2880@L8 vs main 0.2466@L8，all Δ=+4.14pp。
- 100M arm 0.3297@L13 vs main 0.3263@L21，all Δ=+0.34pp。
- 每尺度用 arm/main 各自 de-rRNA best 计算 `Δ_der`；固定原 best 层差作敏感性。符号保持为正才算方向独立支撑，幅度不预设阈值。

### RiNALMoCorpus 复刻（2B 对 2B）

- 30M 0.3259−0.2466=+7.93pp；100M 0.3496−0.3263=+2.33pp；300M 0.3508−0.3445=+0.63pp。
- 重算三个 `Δ_der` 及其 30M→100M→300M 顺序。只有三点均为正且单调不增，才称“正增益随容量衰减”在 de-rRNA 下完整保留；否则逐项标变化。

### b59 预算（5.9B−2B，原 20k/4k 终值协议）

- 30M −5.24pp、100M −2.74pp、300M +3.76pp、650M +1.15pp。
- 每尺度以同一 run 的 2B/b59 各自 de-r best 重算 `Δ_budget_der`，列符号和绝对值；两负两正的模式保持才称尺度依赖模式保留，不把单个符号变化藏进均值。

### P2.5 重测（8k/4k、深层窗、29/43/61）

- 利用 P2.5 新增 per-class 行，按 seed×五层窗选 de-r best；报告 300M/650M 三 seed 均值、ddof=1 和 3 个配对差。
- 3/3 配对仍正才称 de-rRNA 下方向保留；若 P2.5 未产出逐类行，此节 `NOT_EVALUABLE_MISSING_PER_CLASS`，不得用 20k 行替代。

## 4. 种子与统计

无新随机过程；训练/探针种子完全继承输入行。P2.5 的 29/43/61 是探针种子。均值跨训练种子只有原设计已有的尺度才计算，新臂 s17 不虚构 SD。

## 5. 验收与产出

- `$P/evidence/p2_6_derna_layers.csv`：每个 run×ckpt×layer 的 all/der F1、类数、账本来源行。
- `$P/evidence/p2_6_derna_headlines.csv/json`：上述四组对照、独立 best 与固定层敏感性、方向是否保留。
- `$P/evidence/p2_6_derna_coverage.json`：rfamcap 2 尺度、rinalmocorpus 3 尺度、b59 4 尺度及相应 baseline 的覆盖/缺失，P2.5 另列。
- 验收要求 headline 可由 layers CSV 重算、checkpoint 规则无混用、缺失显式标记。只复制 `derRNA_stratified.json` 的四主尺度不算完成。

## 6. 失败降级

- 缺 `per_class_f1`、类名无法识别或 checkpoint 不全：对应格 `NOT_EVALUABLE`，headline 标“未过 de-rRNA 分层”，不得以 all-F1 代替。
- 若非 rRNA 类不足 2 个：不做 macro 均值结论，只公开剩余类并降级。
- 方向反转/衰减模式消失：在主文加限制或撤回强机制表述；不通过改排除规则挽救。
- 本任务不需要也不允许为补 random de-rRNA 而暗中换协议；若未来需要，另预注册保存 random 逐类预测。
