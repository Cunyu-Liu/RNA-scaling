## A. P2.5：650M@5.9B vs 300M@5.9B 重测与原始账本补行

### A1. 保住的主张与边界

保住“同重测协议下 650M@5.9B > 300M@5.9B”的探针读出稳定性证据：旧汇总 **0.4491±0.0147 vs 0.3826±0.0159（ddof=1）**，3/3 probe seeds 配对为正，均值差 +6.65pp。它不是训练种子重复、不是序列 bootstrap，也不证明全层全局最优。

析因主表预算效应仍用原始终值协议 650M 0.3747−2B 0.3632=**+1.15pp**；跨协议 +8.59pp 禁止作 headline。原始终值 20k/4k 下 650M 0.3747@L25 vs 300M 0.3821@L22 的反转保留作协议敏感性。

### A2. 冻结协议

权威脚本：`$B/code_git/reseed_b59_300vs650.py`、`reseed_inner.py`、`rna_sc/probe.py`。

| 项 | 冻结值 |
|---|---|
| run | `RNA-Sc-300M_s17_b59`、`RNA-Sc-650M_s17_b59`，均训练 s17 |
| 权重 | 各目录 latest `ckpt_nt5800296014_step618357.pt`（预算名义 5.9B，实际 nt 如此记录） |
| 数据 | `family_validation` 前 8,000 → `family_test` 前 4,000；parquet 流顺序，ACGU、256nt、非 pad mean-pool、BF16 |
| 层窗 | 300M **L19–23**；650M **L23–27**；0-based |
| probe seeds | **29/43/61**；`probe_one_layer(layer_seed=seed)`，**不再 +layer** |
| 头 | 普通线性、未加类权重；`nn.Linear` 默认初始化且由 probe seed 控制；AdamW lr=1e-3、wd=0.01，8 epochs，batch256 |
| 类映射 | train labels 排序映射；test 未见类过滤；macro-F1 只对 test 实际出现类求均值 |
| 单元 | 2 run×3 seed×5 layer=**30**；每 seed 在各自五层窗内取最大 |

可为省时在每个 run 只收集一次全层 states，再复用于 15 个头；必须证明序列、精度、shape 与原逐单元收集一致。不得改变 probe seed 规则。原脚本每单元重载权重不是科学协议的一部分。

执行版用 `return_pred=True` 额外保存 `per_class_f1` 供 P2.6；这不改变原 30 个 `f1_macro`。原始行至少含 run/layer/probe_seed/ckpt_nt/n_train/n_eval/n_classes/acc/f1_macro/per_class_f1/split/pooling/脚本哈希。

### A3. 终点与逐位验收

1. 30 个单元齐全并写入**新**原始 JSONL，不能仅重写 summary JSON。
2. 与 `$B/eval_evidence_logs/evidence/b59_reseed_300vs650.json` 按 `(run,seed,layer)` 比较四位小数：30/30 逐位一致为直接通过。
3. 任一差异：生成 30 行 diff，分“states 不一致/仅头优化不一致/环境或精度差异/未解释”裁决；保留旧值和新值，禁止覆盖、择近、四舍五入掩盖。未解释差异时验收状态为 `DIFFERENCE_ADJUDICATED_UNRESOLVED`，不得称逐位复现。
4. 每 seed best 应为：300M s29 0.4004@L23、s43 0.3778@L23、s61 0.3697@L22；650M s29 0.4648@L27、s43 0.4468@L24、s61 0.4357@L26。重算 mean±sample SD(ddof=1)及 0.0644/0.0690/0.0660 三个配对差。
5. 产出：`p2_5_b59_reseed_layers.jsonl`、`p2_5_b59_reseed_rerun.json`、`p2_5_b59_reseed_diff.csv`、`p2_5_b59_reseed_summary.csv/json`，均在 `$P/evidence/`；附输入/代码 manifest。

科学终点不是“必须 3/3 为正”：若重跑方向改变，如实判该主张未通过；完成判据是 30 行与差异裁决齐全。

### A4. 失败降级与资源

缺任一层/seed、CUDA fallback 或 latest ckpt_nt 不符即不验收。若无法补齐账本，headline 退回原始终值单种子口径并标重测未固化；不得拿旧 summary 当原始行。

缓存 states 后预计 300M 4–7GB/15–35min，650M 6–10GB/25–60min；若严格逐单元重载，总计可能 3–6h。OOM 只调 states 收集的 `batch_nt` 8192→4096→2048，样本数、层、种子不变。

## B. P2.7：650M_b59 random 切分终值

### B1. 保住的主张与边界

补 random 通道第四尺度终值，检验“random 分数对预算近似免疫”能否从 30M/100M/300M 扩展到 650M。既有 650M −1.85pp 是 **5B midpoint 0.6067@L24 对 2B 0.6252**，不得再当终值。

### B2. 冻结协议

权威脚本：`$B/code_git/run_b59_random.py`、`rna_sc/eval_matrix.py`。

- 模型：`RNA-Sc-650M_s17_b59`，latest `ckpt_nt5800296014_step618357.pt`；参照：`RNA-Sc-650M_s17` 的既有 **random balanced 0.6252@L27**。
- 仅运行 `protocol=probe-balanced, split=random`，不跑默认 CLI 的另外三个 family/meanpool 组合。可直接调用 `eval_matrix.run_one(...)` 或为 CLI 加显式过滤。
- 从 pretraining-held-out `family_validation` 顺序收集 `n_all=24,000`，256nt、非 pad mean-pool、全 28 层；`i%5==0` 4,800 条 eval，其余 19,200 条 train。不是 family_test，也不是从 MLM train 池抽样。
- balanced head：零初始化线性权重，类权重 `min(10,n/freq)`；每层全批 Adam(lr=.05) 200 steps；`layer_seed=17+layer`；best=28 层中最大 macro-F1。
- 终值差 `Δpp=100*(F1_650M_b59−0.6252)`。沿用既有描述性判据 **|Δ|<2pp** 为“近似预算平坦”；≥2pp 或≤−2pp 均否定四尺度免疫的强形式，但仍报告实际值。

### B3. 终点、验收与产出

- 全 28 层结果及 best row 写入 `p2_7_650m_b59_random_layers.jsonl`，汇总写 `p2_7_650m_b59_random.json`；包含 ckpt_nt、n=19200/4800、split/protocol、每层 F1 和输入哈希。
- 更新派生表 `p2_7_b59_random_delta.csv`：30M +0.65、100M −0.60、300M +4.10 原值与 650M 新终值并列；只有新行验收后才把 650M 从 pending 移除。备份 `b59_random_delta.json` 不改写。
- 对照 0.6252 的账本定位必须保留（旧 `eval_matrix_results.jsonl` L34）；若改用其他 2B 数值则协议不一致、不验收。

### B4. 失败降级与资源

若终值未补齐，免疫主张继续限三尺度，650M 只能标 midpoint；不得用 5.8B family 结果或 5B random 中点替代。CUDA 不可用/CPU fallback 即停止。

预计 6–10GB、20–50min。与 P2.5 建议同泳道顺序执行；不得为减少耗时只扫深层窗，random 原协议要求全 28 层。
