# P2.2 预注册：RNS@10 × COV−CTRL 连续相关

- 状态：**已预注册，未执行**；仅已有 30M 权重前向与统计分析。
- `$B` = 只读备份根；`$P` = 项目根 `补证_P2_20261125/`。

## 1. 保住的主张与边界

检验表征邻域组织（RNS）是否与真实前向配对共变知识（COV−CTRL）相关，决定 RNS 能否作为结构可靠性的零监督代理。蛋白结果 ρ≈−0.70 仅作外部参照，不是本任务必须复现的阈值。

旧 `$B/code_git/rna_sc/s14_rns_cov.py` 的实际终点是 **masked-marginal NLL**，不是 COV−CTRL，且其 tie-breaking Spearman 不适合大量离散 RNS 值。本任务必须新算逐序列 COV−CTRL；旧 `s14_rns_cov.json` 的 ρ=0.1429 只能保留为 NLL 敏感性历史结果，不能冒充本任务已完成。

## 2. 设计与共同序列集

- 模型：`RNA-Sc-30M_s17`，最终 2B 留存权重；RNS 层为 `round(0.75*(L−1))`，12 层模型即 **L8**。
- 数据：bpRNA `split=test`，沿用 `s14_rns_cov.py::bpRNA_family_seqs` 的 `source` 作为可获得的最粗家族/来源标签；不得宣称它有细粒度 Rfam ID。
- 按 parquet 顺序每个 source 最多取 40 条，清洗 ACGU、T→U、截断 192 nt，长度≥24；保留至少 12 条的 source。两指标共同使用每个 source 的前 20 条，预计至多 120 条、6 个 source。
- 无任何有效 pair/CTRL 的序列从成对分析剔除；source 在剔除后不足 12 条则不进入家族聚合，但仍保留逐序列行并说明。
- 同一模型、同一批序列、同一 192nt 视图计算 RNS 与 COV；绝对 COV 不与 100 条/256nt 的 Q5 headline 混写。

## 3. 冻结协议

脚本依据：`s14_rns.py`（随机池、mean-pool、RNS）、`s14_rns_ext.py::ours_embedder`（层选择）、`s14_rns_cov.py`（source 队列）、`run_cov300.py`（真正的 COV−CTRL）。

### RNS@10

1. 从上述共同实序列生成 3× 随机池，`make_random_pool(real,3,seed=17)`：长度重采样、mono/di-nucleotide 一阶 Markov 匹配；保存 KS、mono 偏差及 3× 检查，失败则停止。
2. L8 非 pad token mean-pool，BF16、eval；实序列与随机序列 L2 normalize，cosine 最近邻。
3. 在 real∪random 联合池排除自身取 10-NN，`RNS@10 = 随机邻居数/10`，保存逐序列值。均值不是本任务唯一输入，禁止只保存 family 均值。

### 逐序列 COV−CTRL

1. 对每条序列打乱有效 pair 后最多取 20 对，`random.Random(17)`；i/j 按 `run_cov300.py` 转 0-based。
2. mask j，在 j 读原序列及 i 的三种非原碱基突变后的互补碱基概率；`COV = mean[p_mut(COMP[m])−p_orig(COMP[m])]`。
3. 选同时距 i、j 均 >5nt 的 unpaired k，做相同 mask/突变/读出得到 `CTRL`；无合法 k 的 pair 不进入主成对差分。
4. 每条序列先分别平均 COV 与 CTRL，再计算 **per-seq COV−CTRL**；同时保存 cov_n、ctrl_n、pair 数。全局敏感性值按所有 mutation pooled 计算，不与逐序列均值混淆。

## 4. 聚合与统计终点

- 逐序列：Spearman(`RNS@10`, `COV−CTRL`)。使用平均秩处理 ties，不得沿用双重 `argsort` 的任意次序秩；报告 n、ρ及序列 bootstrap 95% CI（seed=17，2,000 次）。
- source/家族：每个 source 对两指标分别作**等权序列均值**，再做 Spearman；报告 source 数、每 source n、ρ。source 数很小，只作描述，不给强显著性结论。
- 散点：逐序列散点（source 着色）和 source 均值散点各一张，标 ρ/n；不得用 family 均值图替代逐序列结果。
- 判决：ρ<0 表示 RNS 越低 COV 越强，与“可靠代理”方向一致；ρ≈0/CI 跨 0 记为未建立代理关系；ρ>0 记为反向。不要求接近 −0.70，也不以 p 值替代效应量。

## 5. 种子

数据/source 顺序按 parquet 固定；随机池=17；COV pair/CTRL 选择=17；bootstrap=17。无探针头、无训练种子重复。

## 6. 验收与产出

- `$P/evidence/p2_2_rns_cov_per_sequence.csv`：sequence ID、source、长度、RNS@10、COV、CTRL、COV−CTRL、有效 pair/mutation 数。
- `$P/evidence/p2_2_rns_cov_per_family.csv` 与 `p2_2_rns_cov.json`：两级 Spearman、n、bootstrap CI、协议和输入哈希。
- `$P/figs/p2_2_rns_cov_sequence.png`、`p2_2_rns_cov_family.png`。
- 验收要求两指标来自完全相同的 sequence ID 集、所有被排除行有原因、随机池 QC 通过、两个 Spearman 与两张散点均可由 CSV 重算。

## 7. 失败降级

- CUDA 不可用或随机池 QC 失败：停止，不用 CPU 或不匹配随机池继续。
- 若只有 masked NLL：维持“真正 RNS×COV 未跑”，不得把旧 NLL 相关写入 COV 结论。
- 若 source 数<3：只报告逐序列相关，家族级标“不可估计”；RNS 作结构代理的主张仍限定/撤回。
