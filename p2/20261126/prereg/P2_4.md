# P2.4 预注册：RNS 分箱控长度三臂判决

- 状态：**已预注册，未执行**；已有权重前向+每层一个固定头，无模型训练。
- `$B` = 只读备份根；`$P` = 项目根 `补证_P2_20261125/`。

## 1. 保住的主张与边界

裁决既有“高 RNS 反而结构 F1 更高”（all-position +18.0%、long-range +29.3%，即 high−low 为正）是否由长度混杂造成，并检验 650M 与 randinit 上是否同样出现。它回答 RNS 轴依赖的机制，不把单一 100M 现象推广成普遍定律。

依据 `$B/code_git/rna_sc/s14_bin_eval.py` 与 `s14_bin_diag.py`。旧 `s14_bin_diag.json` 实际只给长度二分及 len–RNS 相关（Spearman=+0.1915），**没有完成控长度后的 F1 方向判决**。

## 2. 三臂与固定对照

1. `RNA-Sc-100M_s17`：既有现象复测臂，23 层，`L_pick=round(0.75*(L−1))=L16`。
2. `RNA-Sc-650M_s17`：容量对照，28 层，`L_pick=L20`。
3. `RNA-Sc-100M_s17_randinit17`：同 100M 架构随机初始化对照，seed17，L16。

三臂共享 bpRNA TR0/TS0、family_validation 实序列池、同一批预生成随机序列、长度边界、训练头种子和分析代码。650M randinit 不在本“三臂”范围内，不事后添加第四臂择优。

## 3. 冻结前向/探针协议

- RNS 随机池：`stream_real(1500,seed=17)` 从 family_validation 取实序列，`make_random_pool(...,3,seed=17)` 生成 4,500 条；随机池只需生成一次并对三臂复用。保存长度 KS、mono/di 匹配 QC。
- bpRNA：TR0 train、TS0 test；`clean_seq` 为 ACGU-only、T→U、**LEN_CAP=160**。TR0 按 parquet 原顺序取前 2,000 条；TS0 合格集固定为 pairs 非空且清洗后长度≥8 的序列，三臂使用完全相同的 sequence ID。RNS@10 在 TS0 real∪上述 random 联合池中排除自身计算。
- 表征：指定层非 pad token mean-pool（RNS）及逐 token 状态（结构头），eval/BF16，前向 batch=4。
- 结构头沿用 bin 脚本而非 8k S7 头：线性 2 类，Adam(lr=1e-3)，3 epochs，token batch=65,536，类权重 `[n_pos/N,n_neg/N]`。每臂在构头前显式 `torch.manual_seed(17)`，消除旧脚本未设头种子的不可复现性。
- **坐标修正为主口径**：bpRNA pair 是 1-based，统一 `i0=i−1,j0=j−1` 后再判定 `0<=i0,j0<L`。旧 bin 脚本直接用 `m[i]/m[j]`，与 `probe_structure.py` 不一致；旧 0-based 误用仅可作敏感性，主判决不得沿用。
- all-position 指标为每序列 paired 正类 F1 后取均值，不是 macro-F1。long-range 沿用旧定义，只在 `|i0−j0|>=24` 的 pair 位置上计算 paired F1，作为次要 legacy 指标并注明其子集几乎全为正类，不能称标准二分类 macro-F1。

## 4. 控长度设计与判决表

1. 先复算未控长度的全局 RNS terciles（每条臂自身分位点），报告 low/mid/high n、均值、`Δ_raw=F1_high−F1_low`（pp）及相对差。
2. 长度在三臂间与模型无关，使用全体合格 TS0 长度的**固定四分位边界**（`np.quantile([.25,.5,.75])`，依次 `<=q1`、`q1–q2`、`q2–q3`、`>q3`）；每个长度层内再按该臂 RNS terciles 分 low/mid/high。
3. 主估计为长度标准化 `Δ_adj`：在每个长度层分别算 high−low，再按该层 low+high 合格序列数加权。all-position 每 RNS 格至少 n=30、long-range 至少 n=20；不足格不估计，少于 2 个有效长度层则该指标判“不可裁决”。同时公开所有逐层格，禁止只报有利层。
4. 补充 average-rank partial Spearman：对长度、RNS@10、F1 分别取平均秩；以带截距 OLS 分别将 rank(RNS)、rank(F1) 对 rank(长度) 回归，取两残差的 Pearson 相关。另报 len–RNS、len–F1 相关；不得在多种 partial 算法间择优。
5. 序列 bootstrap seed17、2,000 次，给 `Δ_raw/Δ_adj` 95% CI；这是序列重采样，不是训练种子重复。
6. 每臂×两指标填写判决：
   - `Δ_adj<0` 且 CI 全在 0 以下：**翻转为蛋白式高 RNS 降解**；
   - `Δ_adj>0` 且 CI 全在 0 以上：**反向仍存**；
   - 其他：**方向不确定/未过判决**，不得只凭点估计宣称翻转。
   同时列 `Δ_raw` 以显示控长度前后变化；randinit 用于判断该关系是否无需预训练即存在。

## 5. 种子

实序列/随机池=17；randinit=17；每臂结构头=17；bootstrap=17。层位置固定，不在多层中挑最支持某方向的一层。

## 7. 失败降级

- 不修正 pair 坐标、未固定头种子或缺少逐格表：不验收。
- 有效长度层不足/某臂未完成：该臂标不可裁决；若只有 100M，结论仍限 100M，650M/randinit 外推撤回。
- 若控长度后方向未翻转：撤回“长而常见完全解释反向”的假说；若翻转：也只能说该分箱反向主要受长度混杂，不证明 RNS 是普适结构代理。
- OOM 仅将前向 batch 4→2→1；CUDA 不可用或 batch1 仍失败即停止，禁止 CPU 静默降级。

## 8. 资源估算

100M/randinit 每进程约 4–6GB，650M 约 6–10GB（2,000 条逐 token 训练特征与 650M 前向是峰值）；每臂约 20–50 min，三臂串行约 1–2.5h。嵌入可缓存到新 `/teams` 项目目录，但须记录模型/层/数据哈希；统计本身不需 GPU。
