# P2.8 预注册 — 结构读出位置实验（2026-11-27）

> 状态：已预注册，未执行。借鉴 Hallee & Gleghorn, bioRxiv 2026.11.19.767884（READOUT：块内 Q/K/FFN vs 残差流）。
> 保住主张：Q5"配对知识在、缺配对求解器"。检验 ~0.64 读出墙是否为读出位置伪影。

## 假设与判据（先冻结）
- H：注意力 Q/K（位置匹配计算）比残差流更易读出配对信息；若成立，~0.64 墙部分在读出位置。
- 主判据：同任务同切分下，attn_key/attn_query 读出位置的配对净增量（扣匹配先验 0.922 后的 pair AUC，或位置 F1）相对 resid_post 的提升；以 randinit17 与随机旋转方向为对照。
- 破墙定义：某内部位置净增量显著高于 resid_post（bootstrap CI 不重叠）且高于 randinit/旋转对照。
- 两种结果均预注册可写：破墙→"墙部分在读出位置，注意力键携带配对"；不破→"墙在伙伴寻找求解器，非读出位置"。

## 协议
- 模型：RNA-Sc-650M_s17、RNA-Sc-100M_s17（远端 weights/ 已传终值）+ 各 randinit17。
- 数据：bpRNA_parsed.parquet（在位，不依赖缺失 split）；配对位点任务，与 P2.1/Q5 同切分同样本（8000 train / 1305 test，token 口径对齐）。
- 读出位置：resid_post（现口径基线）、attn_query、attn_key、ffn_up（或 gate）。通过 forward hook 捕获 attention 模块 q/k 与 FFN 中间量（评测 instrumentation，不改架构/权重）。
- 探针：每位置独立线性头，**训到收敛**（监控 val loss 平台，早停 patience 冻结）；同层（650M 取 Q5 主层、100M 同）；位置 F1（paired 正类，非饱和）+ pair AUC。
- 对照：randinit17 同位置；随机旋转方向（对激活做随机正交旋转后同探针）证明非平凡。
- 种子：probe seed 17；旋转对照 seed 17/29/43。
- 先验扣除：pair AUC 减无模型组成+距离先验 0.922（与 Q5 同口径）。

## 终点与验收
- 产出：读出位置 × {650M,100M,randinit,旋转} 的位置 F1 / pair AUC / 净增量判决表 + bootstrap CI + manifest+sha256。
- 验收：判据达成或显式降级；对照在位；数字可追溯。

## 失败降级
- hook 捕获 Q/K 不可行 → 限 resid_post + ffn 口径并标注"未测注意力中间量"。
- 探针不收敛 → 该位置标未定，不纳入判决。
